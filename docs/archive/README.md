# Arquivo Historico

Esta pasta guarda documentos preservados por valor de evidencia, decisao ou contexto historico.

Eles nao sao fonte normativa para operacao atual. Quando houver conflito, prevalecem:

1. `AGENTS.md`
2. `BOOTSTRAP.md`
3. `ARCHITECTURE_RULES.md`
4. `docs/README.md`
5. documentos canonicos listados em `docs/README.md`

## Organizacao

- `phase-reports/`: relatorios de validacao, implementacao e estudos por fase.
- `portal/`: plano e tarefas historicas da fachada de portal.
- `side-studies/`: estudos laterais, prompts e propostas fora do runtime canonico.
- `memory/`: memoria operacional antiga preservada como historico.

Caminhos Windows nestes arquivos devem ser lidos como evidencia historica de execucoes passadas, nao como raiz atual do projeto.
