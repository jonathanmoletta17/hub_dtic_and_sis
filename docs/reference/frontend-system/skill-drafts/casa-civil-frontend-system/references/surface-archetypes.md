# Surface Archetypes

## Auth

Must preserve:

- strong first impression
- clear field hierarchy
- readable labels and placeholders
- accessible focus states

Theme risk:

- washed inputs
- weak contrast in helper text
- broken visual emphasis

## Selector

Must preserve:

- context choice clarity
- strong cards or tiles
- obvious navigation

Theme risk:

- category cards blending into canvas
- metadata becoming unreadable

## Dashboard

Must preserve:

- KPI scan speed
- section hierarchy
- card separation
- stable header actions

Theme risk:

- light mode becoming flat and low-energy
- KPI cards losing emphasis

## Ticket List

Must preserve:

- rapid scanning of title, id, status, category, and age
- strong row/card separation

Theme risk:

- muted metadata disappearing
- badges losing semantics

## Ticket Detail

Must preserve:

- event chronology
- sidebar utility
- action clarity

Theme risk:

- timeline washing out
- action panels mixed between themes

## Agent Chat

Must preserve:

- conversational focus
- stable composer
- clear distinction between assistant and user
- obvious review/confirmation states

Theme risk:

- empty canvas feeling unfinished
- bubbles and review panel using theme-incompatible shadows

## Portal

Must preserve:

- product tone instead of prototype tone
- clear service entry
- stable session/error states

Theme risk:

- copy sounding technical or transitional
- cards and headers lacking hierarchy

## Modal Form

Must preserve:

- visual separation from background
- readable form structure
- local submitting feedback

Theme risk:

- modal body inheriting wrong tokens
- low-contrast labels, dividers, and helper text
